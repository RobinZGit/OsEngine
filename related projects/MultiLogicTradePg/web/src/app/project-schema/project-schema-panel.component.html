Где что работает

  • Angular — исполняется в браузере пользователя. Разработка: web/, ng serve --port 4200 (bat-файл MultiLogic_Trade_Progress_Start.bat). Сборка для Pages: ng build → web/dist (base-href /OsEngine/).
  • Node.js — исполняется на сервере/ПК, где установлен проект. Точка входа api/server.js (порт 3000). Внутри одного процесса живут: REST-маршруты (api/routes/*), трейд-раннер (api/trade-runner.js, каждые 15 c), возобновление бэктестов (api/logic-backtest.js), планировщик обслуживания (api/maintenance-scheduler.js). Headless-режим: торговля идёт и без открытого браузера (MultiLogic_Trade_Server_Start.bat).
  • PostgreSQL — исполняется как локальная служба (postgresql-x64-15) на том же ПК, порт 5432. Вся расчётная логика (сигналы, позиции, стопы, бэктест, проскальзывание) реализована SQL-функциями/процедурами из 02_multilogictrade_functions_and_procedures.sql и модулей sql/*.sql.

Перечень модулей

web/ — Angular (UI)

  • web/src/app/logics — логики, тестирование, позиции, бэктест-отчёты
  • web/src/app/terminal — терминал: графики, сделки, индикаторы
  • web/src/app/securities-panel, web/src/app/indicators-panel — бумаги и индикаторы
  • web/src/app/references — справочники (счета, брокеры, биржи; редакторы в *-editor)
  • web/src/app/price-chart — свечной график, контанго, маркеры сделок
  • web/src/app/db-schema — панель «Схема БД» (дерево/диаграмма FK)
  • web/src/app/app-help, web/src/app/app-settings, web/src/app/app-about — справочник, настройки, «О системе»
  • web/src/app/services — HTTP-сервисы к API; web/src/app/models — модели; web/src/app/shared — общие утилиты

api/ — Node.js (сервер)

  • api/server.js — точка входа Express (порт из api/.env, по умолчанию 3000)
  • api/routes/*.js — REST: settings, market, indicators, references, logics, trades, backtest, ops, terminal, internal-tbank
  • api/trade-runner.js — живой цикл торговли (15 с) и сторожевой таймер
  • api/logic-backtest.js, api/logic-rating-precalc.js — бэктест и рейтинг
  • api/lib/* — server-shared, tbank-invest-client, tbank-tls, bond-names, bond-tbru-*, tech-log, logic-bundle, signal-formula, backtest-report*
  • api/maintenance-scheduler.js, api/backtest-report-persist.js — фоновые задачи

sql/ и корень — PostgreSQL

  • 00_create_database.sql, 01_multilogictrade_tables_and_data.sql, 02_multilogictrade_functions_and_procedures.sql, 03_multilogictrade_examples.sql
  • sql/logic_backtest_runner.sql — бэктест (в т.ч. logic_backtest_fill_at — проскальзывание)
  • sql/logic_trade_runner.sql, sql/logic_stop_runner.sql, sql/logic_close_all_positions.sql — торговые циклы
  • sql/load_prices_tbank_http.sql, sql/load_prices_moex_resample.sql, sql/price_load_http_policy.sql — загрузка цен
  • прочее: logic_signal_and_rating, logic_opt, logic_linear_tp, tbank_order_channel, trade_runner_watchdog, app_tech_logging и др.

scripts/ и installer/ — автоматизация

  • scripts/sync-sql-modules-to-02.mjs — перенос sql/*.sql в 02; scripts/sync-project-context-to-assets.mjs — docs в assets
  • scripts/verify-*.mjs — verify-sql, verify-indicators, verify-chart-sync, verify-async-sync, verify-db-upgrade
  • scripts/run_multilogictrade.ps1 — развёртывание БД 00→01→02
  • installer/build-all-installers.ps1 — сборка Windows (Inno Setup) и Linux; номер версии в installer/BUILD_NUMBER
