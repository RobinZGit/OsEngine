Калькулятор Папка базы цен

1. Запуск

Калькулятор — одна HTML-страница + MultiLogic_FinrespCalculator.engine.js в этой же папке. Для загрузки свечей MOEX нужен http://, не file://.

  • Локально: запустите serve-calculator.ps1 → откроется http://127.0.0.1:8765/MultiLogic_FinrespCalculator.html
  • GitHub Pages: онлайн-версия
  • Копия папки: скопируйте всю папку FinrespCalculator — расчёт FINRESP и торговля T-Bank работают без остальных файлов OsEngine

2. Расчёт FINRESP (фиктивный кошелёк)

Таймфреймы: 1, 10, 60 мин и 1 день — напрямую с MOEX ISS. 5 и 15 мин собираются из минутных свечей (OHLCV-агрегация в движке); период для них ограничен (~7–14 дн.), т.к. загрузка идёт по 1-минутным барам.

  1. Выберите акции/фьючерсы (Ctrl+клик), таймфрейм и период.
  2. Выберите логику L1…L5, при необходимости отредактируйте строки в доп. параметрах.
  3. Нажмите Рассчитать — свечи MOEX ISS загрузятся в браузерную базу (IndexedDB).
  4. Двигайте ползунки окна — FINRESP и % годовых пересчитываются сразу.

В блоке результата:

  • FINRESP Σ (с комиссией) — итог по портфелю инструментов с учётом комиссии
  • Комиссии уплачено — сумма удержанных комиссий (отображается как −X ₽)
  • % годовых — простой и сложный, от депозита и календарного периода окна

3. Объём, плечо, комиссия

ПараметрОписание
Volume typeDeposit percent / Contracts / Contract currency — как во вкладке объёма робота
Volume% депозита, число контрактов или сумма в валюте контракта
Депозит (Prime)База для расчёта лота и % годовых
ПлечоMax positions × Volume / 100 (₽), без депозита — например 40 × 10 / 100 = 4 ₽
Commission, %Процент от суммы каждой сделки (покупка и продажа). 0.04 = 0.04%

4. База цен

Свечи хранятся в IndexedDB браузера. Резервная копия — файлы JSON в подпапке price-cache/:

  • Сохранить в файл — выгрузить базу в JSON (положите файл в price-cache/)
  • Загрузить из файла — восстановить или перенести базу на другой ПК
  • Удалить базу цен — очистить IndexedDB

При переносе папки на другой компьютер загрузите сохранённый JSON из price-cache/ через «Загрузить из файла».

5. T-Bank: депозит и реальная торговля

Режимы кошелька (вверху страницы):

РежимНазначение
Фиктивный кошелёкТолько расчёт FINRESP, депозит вручную
T-Bank торговый счётДепозит подтягивается с API (только чтение портфеля)
Реальная торговля T-BankЗаявки на бирже; нужен токен с правом торговли

Токен шифруется в браузере (AES-GCM + PBKDF2), пароль не сохраняется. При выборе T-Bank введите пароль для расшифровки токена.

6. Блок «Реальная торговля»

Внимание: реальные деньги на бирже. Перед «Начать торговлю» проверьте логику, объём и список инструментов.
  • Начать торговлю / Остановить торговлю — синхронизация позиций с расчётом FINRESP; заявки в таблице ниже
  • Продать всё — закрыть все позиции (работает и при остановленной торговле)
  • Тип заявки — рыночная или лимитная (лимит по последней цене из расчёта или last price T-Bank)
  • Портфель — стоимость счёта с позициями (GetPortfolio)
  • Комиссии уплачено (реально) — комиссии брокера из операций T-Bank

7. Дополнительные параметры

  • SL/TP позиции по ATR (@SL, @TP) — как вкладка «Логики» робота
  • Общепортфельный Stopper — SL/TP по equity портфеля
  • Используемые индикаторы — отключённые убираются из Op/Cl до расчёта
  • Строки L1…L5 — редактируемые; «Применить» подставляет @SL/@TP/@LR
  • MOEX тикеры и префиксы фьючерсов — как вкладки робота

8. Диагностика

Блок «Тех. информация» внизу калькулятора — скопируйте при сбое (версия страницы, выбор инструментов, ошибки MOEX/T-Bank).
