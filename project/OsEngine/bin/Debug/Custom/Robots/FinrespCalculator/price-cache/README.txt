База цен калькулятора FINRESP
=============================

Свечи MOEX хранятся в IndexedDB браузера (не в этой папке автоматически).

Сохраняйте сюда JSON-файлы через кнопку «Сохранить в файл» в калькуляторе.
На другом ПК: «Загрузить из файла» и выберите файл из этой папки.

Папка price-cache входит в комплект FinrespCalculator для переноса вместе с резервными копиями базы.
